I've been building software since 2007, mostly in **Java** and **Kotlin**. Across every company I've worked at, my focus has been the same: find the technologies and practices that make applications faster, more stable, and easier to test — then teach the rest of the team how to use them.

That teaching habit turned into books, conference talks, online courses, and a university classroom. Everything you see below has working code in this profile.

🔭 **Currently** — Technical Leader at [TravelX](https://travelx.io) (since 2022) and Associate Professor at UADE (since 2024)

🌱 **Working with** — Kotlin, Ktor, Spring Boot, Kubernetes, MongoDB, and anything that improves test quality

💬 **Ask me about** — microservices, testing strategy, cost optimization in the cloud, technical writing
